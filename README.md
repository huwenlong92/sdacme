# SDACME Releases

This repository distributes release assets for SDACME.

- `sdacme`: certificate management service with the embedded Web interface.
- `sdacmectl`: standalone certificate controller and metadata reporter.

Download versioned packages and SHA256 checksums from [Releases](https://github.com/huwenlong92/sdacme/releases).
Verify the checksums before extracting a package, then follow its README for installation, upgrades and rollback.

Source repositories:

- Rust: https://gitee.com/sd0/sdacme
- Web: https://gitee.com/sd0/sdacme-web

This GitHub repository does not contain production configuration, credentials, private keys or certificate state.
